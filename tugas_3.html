Tugas 3 – Preprocessing Data dan Ekstraksi Fitur TSFEL#

Studi Kasus: Analisis Carbon Monoxide (CO)
Wilayah: Kecamatan Klampis

Penjelasan#

Tugas ini melakukan preprocessing dan ekstraksi fitur pada data konsentrasi Carbon Monoxide (CO) di Kecamatan Klampis, Kabupaten Bangkalan.

Tahapan yang dilakukan meliputi pembentukan data menjadi 365 hari, penanganan missing value, identifikasi dan perbaikan outlier, kemudian ekstraksi fitur menggunakan Time Series Feature Extraction Library (TSFEL).

# ============================================================
# IDENTIFIKASI OUTLIER DENGAN METODE IQR
# ============================================================

Q1 = df_365["CO"].quantile(0.25)
Q3 = df_365["CO"].quantile(0.75)

IQR = Q3 - Q1

batas_bawah = Q1 - 1.5 * IQR
batas_atas = Q3 + 1.5 * IQR

df_365["outlier"] = (
    (df_365["CO"] < batas_bawah) |
    (df_365["CO"] > batas_atas)
)

jumlah_outlier = df_365["outlier"].sum()

print("Q1          :", Q1)

##Contoh Perhitungan Fitur

1 Root Mean Square (RMS)

Contoh data CO: X = [2, -1, 3, -2, 4]

from IPython.display import display, Math

display(Math(r"RMS = \sqrt{\frac{1}{N} \sum_{i=1}^{N} x_i^2}"))
\[\displaystyle RMS = \sqrt{\frac{1}{N} \sum_{i=1}^{N} x_i^2}\]

2 Zero Crossing Rate (ZCR)

Contoh data: X = [2, -1, 3, -2, 4]

Perubahan tanda: 2 → -1 = terjadi perubahan -1 → 3 = terjadi perubahan 3 → -2 = terjadi perubahan -2 → 4 = terjadi perubahan

Jumlah perubahan tanda = 4

Rumus:

display(Math(r"MAD = \frac{1}{N - 1} \sum_{i=1}^{N - 1} |x_{i+1} - x_i|"))
\[\displaystyle MAD = \frac{1}{N - 1} \sum_{i=1}^{N - 1} |x_{i+1} - x_i|\]

3 Mean Absolute Difference

Contoh data: X = [2, 5, 1, 6, 0]

Perhitungan:

MAD = (|5-2| + |1-5| + |6-1| + |0-6|) / 4

MAD = (3 + 4 + 5 + 6) / 4

MAD = 18 / 4

MAD = 4.5

Interpretasi: Nilai 4.5 menunjukkan rata-rata perubahan absolut antara data yang berurutan adalah 4.5

display(Math(r"H = -\sum_i p_i \log_2(p_i)"))
\[\displaystyle H = -\sum_i p_i \log_2(p_i)\]

4 Spectral Entropy

Misalkan distribusi energi frekuensi yang telah dinormalisasi adalah:

p = [0.5, 0.25, 0.25]

Perhitungan: H = -(0.5 log2(0.5) + 0.25 log2(0.25) + 0.25 log2(0.25))

H = -(0.5(-1) + 0.25(-2) + 0.25(-2))

H = -(-0.5 - 0.5 - 0.5)

H = 1.5 bit

Interpretasi: Spectral Entropy sebesar 1.5 bit menunjukkan bagaimana energi sinyal tersebar pada beberapa komponen frekuensi.

Rumus:

display(Math(r"SC = \frac{\sum_k f_k A_k}{\sum_k A_k}"))
\[\displaystyle SC = \frac{\sum_k f_k A_k}{\sum_k A_k}\]

5 Spectral Centroid

Contoh:

Frekuensi: f = [1, 2, 3] Hz

Amplitudo: A = [2, 3, 1]

Rumus:

Perhitungan: SC = ((1×2) + (2×3) + (3×1)) / (2 + 3 + 1)

SC = (2 + 6 + 3) / 6

SC = 11 / 6

SC = 1.83 Hz

Interpretasi: Spectral Centroid sebesar 1.83 Hz menunjukkan titik pusat distribusi energi pada spektrum frekuensi.

Rumus:

display(Math(r"Spread = \sqrt{\frac{\sum_k A_k (f_k - SC)^2}{\sum_k A_k}}"))
\[\displaystyle Spread = \sqrt{\frac{\sum_k A_k (f_k - SC)^2}{\sum_k A_k}}\]

6 Spectral Spread

Definisi: Spectral Spread menunjukkan seberapa luas penyebaran energi frekuensi di sekitar Spectral Centroid.

Cara kerja: Nilai setiap frekuensi dibandingkan dengan Spectral Centroid. Semakin besar penyebaran frekuensi, semakin besar nilai Spectral Spread.

Interpretasi: Spectral Spread digunakan untuk mengetahui apakah energi sinyal terkonsentrasi pada rentang frekuensi tertentu atau tersebar pada rentang yang lebih luas.

display(Math(r"X[k] = \sum_{n=0}^{N-1} x[n] e^{-j 2 \pi k n / N}"))
\[\displaystyle X[k] = \sum_{n=0}^{N-1} x[n] e^{-j 2 \pi k n / N}\]
